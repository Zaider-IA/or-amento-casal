Chaves dos avisos do Zelo

As chaves são criadas aqui, no seu aparelho. Nada é enviado para a internet.

1) Rode no SQL Editor do Supabase
Toque no texto, copie tudo e cole.
2) Cadastre em Edge Functions → Secrets
Um por linha: nome = valor.

Guarde a chave privada só no Supabase. Depois de usar, apague este arquivo (chaves.html) do GitHub.
